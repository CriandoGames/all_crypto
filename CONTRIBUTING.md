# Contribuindo

Use Dart compatível com o SDK mínimo, formate com `dart format .` e execute `dart analyze`, `dart test` e `dart pub publish --dry-run`. Alterações em algoritmo ou serialização exigem vetores reproduzíveis, teste de compatibilidade anterior e descrição de segurança. Não inclua chaves, tokens, payloads reais ou dados pessoais em issues e fixtures.
